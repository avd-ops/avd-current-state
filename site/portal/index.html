What gets removed

Anything that looks like a password, key or token; email addresses and UPNs; tenant and domain names; IDs; public IP addresses; user names in paths; subscription and resource group names (from your settings and the output); resource names in Azure resource IDs; storage and key vault names; and the words you add below. Server names the output prints any other way are not found: add them. Nothing leaves this page until you submit the issue on GitHub, which needs a GitHub account.

      What the command does
      
      The collector reads what is in your subscriptions through Resource Graph and writes an evidence package in Cloud Shell. Then the facts script gives the estate a pseudonym, which the later steps use instead of any name. Both only read. Run each command in Azure Cloud Shell and paste the output back: nothing you paste or type leaves this page unless you send a report yourself.
      
    
      
    
      Running it on a schedule? Check the optional reader
      
      An optional read-only identity lets GitHub Actions in your private repo run the collector with nobody signed in. Set it up from the reader guide; this check only reads.

      What review.json holds
      
      The decisions become review.json (avd-assessment-review/v1), which pins the report by its hash and holds only check IDs and reason codes. A note on a finding goes to your private notes file. The block writes it beside the evidence packages.

      What goes into the plan
      
      The findings you chose to fix, and every finding nobody reviewed, become an ordered plan: what good looks like and why, the landing zone parameter or setting that changes it where one is known, and what is outside the landing zone's reach. Accepted and deferred findings stay out. Saved as plan.json (avd-remediation-plan/v1), which holds only check IDs, citations and public values, and plan.md for people.
      
      
      A landing zone change fixes only what the landing zone deployed. A finding on a resource it doesn't own is changed where that resource is managed.
