About avd-current-state

Walks an avd-current-state assessment step by step. Run each command in Azure Cloud Shell (PowerShell), paste the output back here, and answer the discovery questions. Everything happens in your browser: nothing you paste or type is sent anywhere, and every command only reads.

Personal project, not for production. Provided as is, without warranty of any kind (MIT License). Not affiliated with, endorsed by or supported by the author's employer, and not an official Microsoft product. Not a certification, a compliance attestation or a security audit.
